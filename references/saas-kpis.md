# Метрики B2B-софта по подписке

Использовать только для софта по подписке для компаний. Целевых значений здесь нет: цели у каждой компании свои, это не нормы рынка.

| Метрика | Как считать |
|---|---|
| LTV / CAC | пожизненная ценность клиента ÷ стоимость его привлечения |
| Чистое удержание выручки по когортам (NRR) | регулярная выручка когорты через год с учётом расширений, сокращений и оттока ÷ её выручка год назад |
| Отток и сокращения к выручке на продление | потерянная и сокращённая регулярная выручка ÷ регулярная выручка, которая подходила к продлению за период |
| «Правило 40» | темп роста выручки, % + маржа по EBITDA или свободному денежному потоку, % |
| Запас денег (runway) | деньги на счёте ÷ среднемесячный чистый расход, в месяцах |
| Дни дебиторки | через сколько дней после выставления счёта клиенты платят |
| Покрытие воронки | сумма сделок в воронке с закрытием в периоде ÷ план продаж на период |
| Эффективность маркетинга | новая регулярная выручка за период ÷ расходы на маркетинг за тот же период |
| NPS платящих клиентов | готовность рекомендовать продукт среди тех, кто платит |
| Доля покупок без продавца | сделки через самообслуживание ÷ все сделки |
